# Sugestão de publicação para o LinkedIn

🚀 Novo projeto de portfólio: HelpDesk API

Desenvolvi uma API REST para gerenciamento de chamados de suporte técnico, aplicando conhecimentos de desenvolvimento backend com Python.

🛠️ Tecnologias utilizadas:
- Python
- Django
- Django REST Framework
- PostgreSQL
- APIs REST
- JWT
- Swagger/OpenAPI
- Git e GitHub

A aplicação possui CRUD completo de chamados, autenticação, filtros, busca, paginação e regras de acesso por usuário.

O projeto também me permitiu unir minha experiência com suporte de TI aos meus estudos em desenvolvimento de software.
